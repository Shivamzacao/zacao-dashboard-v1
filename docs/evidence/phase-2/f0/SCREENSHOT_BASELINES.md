# F0 Screenshot Baselines

The baselines are viewport captures of the approved live demo. Desktop is `1280 × 720`; tablet
landscape is `1024 × 768`. Each of the eight demo sections has both captures. Insights also has both
captures for its distinct Data Validation Matrix state.

Artifacts live in `docs/evidence/phase-2/f0/baselines/` and are named:

- `{executive|revenue|customers|products|marketing|growth|financial|insights}-{desktop-1280x720|tablet-1024x768}.jpg`
- `insights-data-validation-{desktop-1280x720|tablet-1024x768}.jpg`

These 18 files are immutable F0 references after approval. The first full-page tablet capture was
discarded during F0 because the capture mechanism distorted responsive geometry; one permitted
corrective pass produced the final viewport-accurate files. The live demo itself was not changed.
